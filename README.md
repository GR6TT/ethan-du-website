# Ethan Du / 杜易展

Source code for the official personal website of Ethan Du.

[Visit the live website](https://ethan-du.duyzan.chatgpt.site)

## Overview

The website presents a bilingual selection of Ethan Du's public work:

- media coverage and selected milestones;
- public writing, social channels, and video collections;
- project work spanning marketing, entrepreneurship, and technology.

## Featured work

- **City Trendbook Marketing Plan** — a national champion project from the Taobao marketing competition.
- **Refresh Journal** — a university-community shoe and garment care venture developed with local retail partners.

## Technology

- React 19 and TypeScript
- vinext and Vite
- responsive, motion-led interface
- OpenAI Sites deployment

## Local development

```bash
npm ci
npm run dev
```

Node.js 22.13 or newer is required.

## Status

This is an actively maintained portfolio. Content and project claims are curated for public presentation by Ethan Du.
